## [0.1.0] - 2026-09-04

### Added

- `hunk gh pr` for reviewing GitHub pull requests in Hunk.
- `hunk gh commit` for reviewing GitHub commits by SHA, URL, or `owner/repo@sha` shorthand.
- `hunk gh compare` for reviewing the diff between branches, tags, or commits.
